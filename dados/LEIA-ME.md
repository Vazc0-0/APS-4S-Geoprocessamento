# Pasta de dados

Extraia aqui o **DadosAPS.zip** enviado pelo professor.

Depois de extrair, a estrutura deve ficar assim:

```
dados/
└── DadosAPS/
    ├── 10/
    │   ├── Com Duplicidade/
    │   │   ├── Aleatório/
    │   │   ├── Concavo-DecresceCresce/
    │   │   ├── Convexo-CresceDescresce/
    │   │   ├── Crescente/
    │   │   └── Descrescente/
    │   └── Sem Duplicidade/
    ├── 50/  100/  500/  1k/  5k/  10k/  50k/  100k/
```

No Windows: clique com o botão direito no zip → **Extrair Tudo…** → escolha esta pasta `dados`.

Não renomeie as pastas. O sistema encontra as pastas mesmo que o acento de "Aleatório" venha estragado do zip.

Esta pasta fica fora do Git (veja `.gitignore`), porque os dados têm 158 MB.
